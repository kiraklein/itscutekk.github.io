# Velceron

Velceron is a lightweight AI governance prototype by Klein Consulting Ltd.

It turns a short AI-system assessment into:

- risk classification
- evidence gaps
- recommended controls
- a decision record
- a printable governance pack
- JSON export

## Privacy

The prototype runs client-side in the browser. Assessment answers are not sent to a Velceron backend.

## Status

Prototype / design-partner stage. Decision support only; it does not replace legal, regulatory, security or risk review.
